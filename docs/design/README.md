# Design authority

Design is authoritative in the **authored** Obsidian vault, in existing **InferOS …** notes
under **software/InferOS/**. This directory is retired; do not add local design files or pointers.

Each [architecture topic](../architecture/README.md) lists the canonical notes and optional
section headings it supports in `obsidian_designs`. See [InferOS brain](../architecture/_brain.md)
for discovery, conceptual searches and the Obsidian CLI read/edit/readback workflow.

The former pillars, template, API declaration and review scenarios have been absorbed into
those notes. Drafts and open questions remain drafts; current owner decisions take precedence
over explicitly dated repository proposals. Architecture, ADRs and implementation evidence
remain in Git. CI validates repository references without requiring access to the private vault.
